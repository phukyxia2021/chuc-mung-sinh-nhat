# TRANG WEB CHÚC MỪNG SINH NHẬT (MOBILE FIRST) 🎉🎂

Trang web chúc mừng sinh nhật được tối ưu hoàn hảo cho nền tảng điện thoại di động với giao diện hiện đại, animation mượt mà 60 FPS, âm thanh Web Audio sống động và pháo hoa rực rỡ.

## 📱 Cách mở trên điện thoại di động:
1. **Cách nhanh nhất**: Mở trực tiếp file `index.html` bằng trình duyệt trên điện thoại hoặc máy tính (Chrome, Safari, Edge,...).
2. **Chạy qua mạng nội bộ để bạn bè cùng mở trên điện thoại**:
   - Mở Terminal/PowerShell tại thư mục `c:\Chuc_mung_sinh_nhat`
   - Gõ: `python -m http.server 8000`
   - Dùng điện thoại kết nối cùng WiFi và truy cập `http://<IP_MÁY_TÍNH>:8000`
